# Проверка исправлений после студенческого прогона

## Даты и доступность сведений

Истёкший срок остаётся доказательством для вопросов «до какого числа?», «я опоздал?»
и «какой срок был?». При наличии подтверждённой связи исходное объявление передаётся
вместе с продлением или исправлением. Ручной архив по-прежнему исключает публикацию
из ответов. Отсутствие срока не подтверждает, что вакансия открыта.

Дата публикации, дата редактирования, дата мероприятия и срок регистрации учитываются
раздельно. Поиск событий за период относится к проведению события; запрос публикаций
за период — ко времени публикации. Исторические запросы не ограничены предстоящими
событиями. Связанные уточнения не должны превращать прошедшее событие в новое.

Дата без года не получает год публикации автоматически. Такие сведения остаются
неопределёнными до уточнения. Администратор может [подтвердить дату](date-confirmation.md).
Если Telegram-пост изменится, прежнее подтверждение перестанет действовать. При
нескольких датах или неоднозначном периоде бот должен сообщить неопределённость.

Ссылки в ответе ведут к найденным публикациям; приватный канал по-прежнему требует
доступа в Telegram. Отсутствие результата поиска не означает отсутствие информации
во всём канале. Проверка календарных дат блокирует подстановку даты публикации
вместо даты из текста; она не заменяет проверку того, к какому событию относится факт.

## Запуск обновлённой версии

Остановить текущий BackendApplication, сохранить резервную копию используемой базы,
затем запустить обновлённый проект на Java 21 с прежними переменными среды.
Одновременно запускать два экземпляра polling-бота с одним токеном не нужно.

Миграция V16 добавляет подтверждения дат и сбрасывает старые автоматические решения
об актуальности для повторной проверки. V17 добавляет отдельную дату мероприятия и
помечает метаданные событий для повторного извлечения. Исходные публикации и ручной
архив сохраняются. Фоновая обработка должна завершиться перед повторным студенческим
прогоном; её результат виден в карточках публикаций.

Откат к старому коду после миграций следует делать вместе с соответствующей копией
базы. Ветка Git сохраняет код, но не является резервной копией PostgreSQL.

Для кнопки администратора сохранить ADMIN_ENABLED, ADMIN_TELEGRAM_USER_IDS и действующий
ADMIN_PUBLIC_URL. После запуска кнопка меню открывает панель напрямую; команды доступны
на дополнительной клавиатуре. Подробности — [админ-панель](admin-panel.md). Публичный
HTTPS-доступ всё ещё требует работающего туннеля либо отдельно настроенного хостинга.

## Ручной прогон в Telegram

- Спросить об истёкшем сроке сдачи документов и затем об известном продлении.
- Повторить вопросы о практике, вакансиях и событиях на русском, казахском и английском,
  включая опечатки и смешанный запрос из нескольких тем.
- Сравнить дату Open Space в исходном посте и ответе. Отдельно запросить прошедшие
  и предстоящие события; проверить уточнение времени и частичную отмену условия.
- Для поста с «1 апреля» без года проверить неопределённый статус, подтвердить год
  в панели, повторить вопрос, затем изменить источник и проверить отмену подтверждения.
- Проверить вход администратора через прямую кнопку, быстрые команды и отказ
  пользователю вне списка администраторов.

Скорость в логах backend измеряет обработку сообщения сервером; доставка Telegram,
создание embeddings, заполненность индекса и нагрузка внешних AI-провайдеров добавляют
своё время. Синтетический прогон моделей следует рассматривать отдельно от измерения
полного пути сообщения на телефоне.
