# Подтверждение неоднозначных дат

Год публикации больше не подставляется в дедлайн автоматически. Фразы без года
(например, «1 апреля» в июльском посте) сохраняются со статусом «Срок не определён».
Явный год, а также однозначные «этого года», «следующего года», `this year`, `next year`,
«биыл», «келесі жылы» учитываются относительно даты публикации, а не даты запроса.
Выдуманный год в AI-метаданных не заменяет исходный текст.

«До 7 сентября» и «7 қыркүйекке дейін» не считаются доказательством прекращения приёма
в начале указанного дня. Для поиска используется конец дня с явным предупреждением,
что возможность подачи в последний день требует уточнения. Однозначное «строго до»
или `before` исключает день; «включительно», «по», `through` включает его.

Администратор открывает публикацию → «Подтвердить дату», указывает полную дату,
назначение (подача документов/заявки, мероприятие, окончание практики), включительность
последнего дня и основание уточнения. Для мероприятия день проведения включается.
Исходный текст при этом не изменяется. Состояние актуальности пересчитывается,
поисковый индекс получает событие обновления. В журнале сохраняются проверенный
Telegram ID администратора, дата, назначение, граница и основание.

Подтверждение привязано к тексту, времени публикации и времени Telegram-редактирования.
Оно перестаёт действовать при изменении источника. Отменить его можно отдельным действием
с причиной; затем снова применяется автоматический разбор источника. Конкурирующие
изменения защищены ревизией записи: при конфликте панель нужно обновить.

API: `PUT /api/admin/posts/{id}/date-confirmation` принимает `revision`, `date` (ISO),
`boundary` (`INCLUSIVE`/`EXCLUSIVE`), `purpose`, `reason`.
`POST /api/admin/posts/{id}/date-confirmation/revoke` принимает `revision`, `reason`.
Оба действия доступны только через существующую проверку подписи Telegram и списка администраторов.
